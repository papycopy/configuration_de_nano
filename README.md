# configuration de nano

vous pouvez configurer nano l editeur de texte via le terminal
il y a deja plein de parametres commenté que vous pouvez activer ou non
sudo nano /etc/nanorc pour tout les utilisateurs
si c est uniquement pour vous que vous voulez changer des parametres il vous faudra créer un fichier .nanorc dans votre home
pour plus d infos tapez la commande pour voir le manuel
    man nanorc
pour moi celle qui est le plus pratique c est d afficher les numéros de lignes
set linenumbers
donc je l ai décommenter et enregistré
ctrl xpour enregistrer
et o  pour accepter les modifications
puis entrer pour valider le nom du fichier
